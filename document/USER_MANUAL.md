## 1. บทนำและบทบาทผู้ใช้งาน

ระบบแบ่งผู้ใช้งานออกเป็น 2 กลุ่มหลัก:
1. **ผู้สมัครงาน (Applicant)**: บุคคลภายนอกที่ต้องการสมัครงาน และผู้สมัครที่ได้รับคัดเลือกให้ทำแบบทดสอบออนไลน์
2. **เจ้าหน้าที่ HR / ผู้ดูแลระบบ (Admin)**: เจ้าหน้าที่ผู้รับผิดชอบการรับสมัคร ตรวจสอบประวัติ ออกรหัสสอบ สร้างข้อสอบ ตรวจให้คะแนน และสรุปผล

## 2. คู่มือสำหรับผู้สมัครงาน (Applicant)

### 2.1 การกรอกใบสมัครงานออนไลน์
- **ลิงก์เข้าใช้งาน**: เข้าผ่านหน้าแรกของเว็บไซต์ หรือพิมพ์ URL: `/apply`
- **ขั้นตอนการกรอกข้อมูล**:
  1. **เลือกตำแหน่งงานและเงินเดือน**: เลือกตำแหน่งที่ต้องการสมัครจากรายการที่เปิดรับ พร้อมระบุเงินเดือนที่คาดหวัง
  2. **ข้อมูลส่วนบุคคล**: กรอกชื่อ-นามสกุล ทั้งภาษาไทยและภาษาอังกฤษ, วันเดือนปีเกิด, สัญชาติ, ศาสนา, ข้อมูลสุขภาพ และประวัติทั่วไป
  3. **ข้อมูลการติดต่อ**: เบอร์โทรศัพท์, อีเมล, Line ID, โซเชียลมีเดีย และที่อยู่ปัจจุบัน
  4. **ข้อมูลบัตรประจำตัวประชาชน**: เลขประจำตัวประชาชน 13 หลัก และเลขหลังบัตรประชาชน (Laser ID)
  5. **ประวัติครอบครัวและการเกณฑ์ทหาร**: ข้อมูลคู่สมรส, บิดา-มารดา, พี่น้อง, สถานะทางทหาร
  6. **ประวัติการศึกษาและประวัติการทำงาน**: เพิ่มสถาบันการศึกษา, เกรดเฉลี่ย, ประวัติการทำงานเดิม และบุคคลอ้างอิง
  7. **อัปโหลดเอกสารสำคัญ**:
     - รูปถ่ายหน้าตรง
     - สำเนาบัตรประชาชน
     - สำเนาทะเบียนบ้าน
     - ใบรายงานผลการศึกษา (Transcript)
     - ประวัติย่อ (Resume / CV)
  8. **การยินยอมข้อมูลและลงชื่อ**: ตรวจสอบข้อตกลง PDPA ความถูกต้องของข้อมูล และพิมพ์ชื่อแทนการลงนามก่อนกดยืนยันการส่งใบสมัคร

### 2.2 การเข้าสู่ห้องสอบออนไลน์
เมื่อใบสมัครได้รับการคัดเลือกจากฝ่ายบุคคล ผู้สมัครจะได้รับ **Username** และ **Password** พร้อมกำหนดวันหมดอายุสอบทางอีเมลหรือการติดต่อจาก HR
1. เข้าไปที่ URL: `/exam/login`
2. กรอก **Username** และ **Password** ที่ได้รับ
3. เมื่อเข้าสู่ระบบสำเร็จ จะพบหน้า **Welcome**:
   - ตรวจสอบชื่อ-นามสกุล และตำแหน่งงานที่สมัคร
   - ตรวจสอบวันหมดอายุสิทธิ์สอบ (Exam Deadline)
   - อ่านคำชี้แจงและกฎระเบียบการสอบอย่างละเอียด
4. กดปุ่ม **"ไปยังรายการแบบทดสอบ"** เพื่อเข้าสู่ Exam Dashboard

### 2.3 การทำแบบทดสอบและข้อควรระวัง
1. **การเริ่มทำแบบทดสอบ**:
   - คลิกปุ่ม **"เริ่มทำข้อสอบ"** ในชุดแบบทดสอบที่ต้องการ
   - หน้าจอจะเปิดโหมดเต็มหน้าจอ (Fullscreen) และเริ่มนับเวลาถอยหลัง (Timer) ทันที
2. **รูปแบบข้อสอบ**:
   - **ปรนัยเลือก 1 ข้อ (Single Choice)**: คลิกเลือกคำตอบที่ถูกต้องที่สุด 1 ข้อ
   - **ปรนัยเลือกหลายข้อ (Multiple Choice)**: ติ๊กเลือกคำตอบที่ถูกต้องได้มากกว่า 1 ข้อ
   - **อัตนัย (Essay)**: พิมพ์คำตอบในช่องข้อความ หรืออัปโหลดไฟล์คำตอบเพิ่มเติม (ถ้ามี)
3. **⚠️ ข้อควรระวังอย่างยิ่ง (ระบบ Anti-Cheating)**:
   - **ห้ามสลับแท็บเบราว์เซอร์ ห้ามเปิดโปรแกรมอื่น หรือย่อหน้าต่าง**
   - **ห้ามออกจากโหมดเต็มหน้าจอ**
   - ระบบจะตรวจจับและบันทึกจำนวนครั้งที่สลับหน้าจอ พร้อมวันเวลาที่กระทำลงในฐานข้อมูลทันที และรายงานต่อ HR เพื่อใช้ประกอบการพิจารณาตัดสิทธิ์
4. **การส่งข้อสอบ**:
   - เมื่อทำครบทุกข้อให้กดปุ่ม **"ส่งข้อสอบ"** หรือระบบจะทำการส่งอัตโนมัติเมื่อหมดเวลา

## 3. คู่มือสำหรับเจ้าหน้าที่ HR และผู้ดูแลระบบ (Admin)

### 3.1 การเข้าสู่ระบบ Dashboard
1. เข้าไปที่ URL: `/login`
2. กรอก **Username / Email** และ **Password** (ค่าเริ่มต้น: `admin` / `Admin@1234`)
3. เมื่อเข้าสู่ระบบจะพบหน้า **Dashboard** ซึ่งแสดง:
   - สรุปจำนวนผู้สมัครทั้งหมด
   - จำนวนผู้สมัครที่รอการตรวจสอบ
   - จำนวนผู้สมัครที่กำลังสอบ หรือรอตรวจข้อสอบ
   - สถิติตำแหน่งงานที่ได้รับความนิยม

### 3.2 การจัดการตำแหน่งงานที่เปิดรับ
- **เมนู**: **"จัดการตำแหน่งงาน"** (`/admin/positions`)
- **การเพิ่มตำแหน่ง**: กรอกชื่อตำแหน่งใหม่ แล้วกด "เพิ่มตำแหน่ง"
- **การเปิด/ปิดรับสมัคร**: สามารถคลิกสลับสถานะ (Active / Inactive) ได้ตลอดเวลา

### 3.3 การตรวจสอบและคัดกรองใบสมัครงาน
- **เมนู**: **"ผู้สมัครงาน"** -> เลือกดูรายชื่อผู้สมัคร
- เข้าดูรายละเอียดผู้สมัคร (`/admin/applicants/{id}`) เพื่อ:
  - ตรวจสอบประวัติส่วนตัว การศึกษา และประวัติการทำงาน
  - เปิดดูเอกสารแนบ (บัตรประชาชน, ทรานสคริปต์, เรซูเม) ผ่านระบบ Secure Stream
  - บันทึกการตรวจสอบ: ติ๊กเลือกผลการตรวจ **Blacklist**, **ประวัติอาชญากรรม**, **Social Media**
  - ใส่บันทึกความเห็น HR (Verification Note)
  - ปรับสถานะเป็น **"ผ่านคุณสมบัติ (Qualified)"** หรือ **"ไม่ผ่านคุณสมบัติ (Disqualified)"**

### 3.4 การออกรหัสผ่านและกำหนดสิทธิ์สอบ
- **เมนู**: **"ออกรหัสสอบ"** (`/admin/applicant-accounts`)
- ขั้นตอน:
  1. เลือกผู้สมัครที่มีสถานะ Qualified
  2. กำหนด **วันหมดอายุสิทธิ์สอบ (Exam Deadline)**
  3. ระบบจะ Generate Username และ Password สุ่มอัตโนมัติ
  4. สามารถคัดลอก (Copy) หรือกดดูรหัสผ่านเพื่อส่งต่อให้ผู้สมัครทางอีเมลหรือโทรศัพท์ได้ทันที

### 3.5 การสร้างและจัดการคลังข้อสอบ
- **เมนู**: **"จัดการข้อสอบ"** (`/admin/exams`)
- **การสร้างชุดข้อสอบใหม่**:
  - ระบุชื่อชุดข้อสอบ, คำอธิบาย, เวลาในการทำข้อสอบ (นาที), เกณฑ์เปอร์เซ็นต์ที่ผ่าน
  - เลือกว่าเป็นข้อสอบสำหรับ **"ทุกตำแหน่ง (All)"** หรือ **"เฉพาะตำแหน่งที่เลือก (Specific)"**
- **การเพิ่มข้อคำถาม (Questions)**:
  - เลือกประเภท: Single Choice, Multiple Choice, หรือ Essay
  - พิมพ์โจทย์คำถาม และอัปโหลดภาพประกอบโจทย์ (ถ้ามี)
  - กำหนดคะแนนประจำข้อ
  - สำหรับข้อปรนัย ให้เพิ่มตัวเลือกและกำหนดข้อที่ถูกต้อง

### 3.6 การตรวจให้คะแนนและตรวจสอบพฤติกรรมระหว่างสอบ
- **เมนู**: **"ตรวจข้อสอบ"** (`/admin/exam-review`)
- ระบบจะตรวจและคิดคะแนนข้อปรนัยให้อัตโนมัติทันทีที่ผู้สมัครส่งข้อสอบ
- คลิกที่รายการที่ขึ้นสถานะ **"รอตรวจ (Awaiting Review)"**:
  - ตรวจดูคำตอบข้อเขียนอัตนัย หรือเปิดดูไฟล์แนบที่ผู้สมัครส่งมา
  - ให้คะแนนในแต่ละข้อพร้อมใส่ความคิดเห็น
  - **ตรวจสอบแถบรายงาน Anti-Cheating**: หากพบว่ามีจำนวน `suspicious_activity_count` มากกว่า 0 จะมีตารางแสดงเวลาที่ผู้สอบสลับแท็บอย่างชัดเจน
  - กดยืนยันผลคะแนนเพื่ออัปเดตสถานะ

### 3.7 รายงานสรุปผลภาพรวม
- **เมนู**: **"สรุปผลภาพรวม"** (`/admin/summary`)
- รวบรวมข้อมูลผลการประเมินของผู้สมัครทุกคน:
  - สถานะผลการคัดกรอง, คะแนนสอบแต่ละชุด, ผลสรุปว่าผ่านหรือตก
  - สามารถพิมพ์รายงานผล หรือกดดูสรุปประวัติแบบละเอียด (`summary-applicant-detail`)

## 4. คำถามที่พบบ่อยและการแก้ปัญหา (FAQ)

### Q1: บัญชีผู้สอบเข้าสู่ระบบไม่ได้ แจ้งว่าหมดอายุ?
- **ตอบ**: ให้ HR ไปที่หน้า **"ออกรหัสสอบ"** (`/admin/applicant-accounts`) ตรวจสอบวัน `Exam Deadline` ของผู้สมัครรายนั้น หากหมดอายุแล้ว สามารถแก้ไขขยายเวลา และแจ้งให้ผู้สมัครเข้าสู่ระบบใหม่อีกครั้งได้

### Q2: รูปภาพหรือเอกสารแนบของผู้สมัครไม่แสดง?
- **ตอบ**: ไฟล์แนบถูกเก็บไว้ในที่ปลอดภัย (Secure Storage) ต้องเข้าสู่ระบบในฐานะ Admin จึงจะสามารถเปิดดูได้ และโปรดตรวจสอบว่าสิทธิ์การเขียนอ่านโฟลเดอร์ `storage/app/private` บนเซิร์ฟเวอร์ได้รับการตั้งค่าถูกต้อง

### Q3: รหัสผ่านเริ่มต้นของผู้ดูแลระบบคืออะไร?
- **ตอบ**: 
  - **Username**: `admin`
  - **Password**: `Admin@1234`
  *(แนะนำให้เปลี่ยนรหัสผ่านทันทีหลังจากการติดตั้งผ่านหน้าโปรไฟล์)*
