# แบบทดสอบการยอมรับระบบและคู่มือตรวจสอบ (UAT & Testing Checklist)
## ระบบรับสมัครงานและทดสอบออนไลน์ SKP (SKP-Exam)

เอกสารฉบับนี้ใช้สำหรับทีมงานผู้พัฒนา, ผู้ทดสอบระบบ (QA/Tester), และเจ้าหน้าที่ฝ่ายทรัพยากรบุคคล (HR) ในการตรวจสอบความถูกต้องก่อนการส่งมอบและเปิดใช้งานระบบจริง (Go-Live)

---

## สรุปภาพรวมสถานการณ์ทดสอบ (Test Scenarios Matrix)

| รหัสชุดทดสอบ | หัวข้อการทดสอบ | ผู้เกี่ยวข้อง | ผลลัพธ์ที่คาดหวัง |
| :---: | :--- | :---: | :--- |
| **TC-01** | การกรอกใบสมัครงานออนไลน์และแนบเอกสาร | ผู้สมัคร | ส่งใบสมัครสำเร็จ, สถานะเป็น `submitted` |
| **TC-02** | การคัดกรองประวัติและตรวจสอบเอกสารแนบ | HR / Admin | ดูเอกสารได้ปลอดภัย, ปรับเป็น `qualified` |
| **TC-03** | การออกรหัสสอบและกำหนดวันหมดอายุ | HR / Admin | รหัสสุ่มถูกสร้าง, สถานะเป็น `code_generated` |
| **TC-04** | การสร้างและจัดการชุดแบบทดสอบ | HR / Admin | บันทึกข้อสอบทุกประเภทถูกต้องตามตำแหน่ง |
| **TC-05** | การเข้าสอบและระบบตรวจจับการทุจริต | ผู้สมัคร | จับเวลาถอยหลัง, ตรวจจับการสลับแท็บได้จริง |
| **TC-06** | การตรวจให้คะแนนและสรุปผลการสอบ | HR / Admin | คะแนนคำนวณถูกต้อง, สรุปผลผ่าน/ไม่ผ่าน |
| **TC-07** | หน้าสรุปผลภาพรวมและรายงานผล | HR / ผู้บริหาร | ข้อมูลสรุปสอดคล้องกับผลการสอบทั้งหมด |

## รายละเอียดขั้นตอนการทดสอบ (Detailed Test Cases)

### TC-01: การกรอกใบสมัครงานออนไลน์ (`/apply`)
- [ ] **1.1 ฟิลด์ข้อมูลจำเป็น (Required Fields)**: เมื่อกดส่งโดยไม่กรอกข้อมูล ระบบต้องแจ้งเตือน Validation ชัดเจน
- [ ] **1.2 การคำนวณอายุและวันเกิด**: เลือกวันเดือนปีเกิด ระบบจัดเก็บฟอร์แมต `YYYY-MM-DD` ถูกต้อง
- [ ] **1.3 การเพิ่มรายการซ้ำ (Dynamic Rows)**:
  - ประวัติการศึกษา: สามารถเพิ่มได้มากกว่า 1 สถาบัน และลบแถวได้
  - ทักษะทางภาษา: เพิ่มภาษาและระดับความชำนาญ (พูด/อ่าน/เขียน) ได้
  - ประวัติการทำงานเดิม: สามารถระบุหลายบริษัทพร้อมเหตุผลที่ลาออกได้
- [ ] **1.4 การอัปโหลดเอกสารสำคัญ**:
  - อัปโหลดรูปถ่ายหน้าตรง, สำเนาบัตรประชาชน, ทะเบียนบ้าน, ทรานสคริปต์, เรซูเม
  - ทดสอบไฟล์ชนิด `.pdf`, `.jpg`, `.png` ขนาดไม่เกินที่กำหนด (เช่น 10MB)
- [ ] **1.5 ข้อตกลงความยินยอม (Consent)**: ต้องติ๊กยอมรับความถูกต้องและ PDPA จึงจะส่งได้
- [ ] **1.6 ผลลัพธ์**: หน้าจอแสดงข้อความส่งใบสมัครสำเร็จ และในฐานข้อมูลขึ้นสถานะ `submitted`

---

### TC-02: การคัดกรองประวัติและตรวจสอบเอกสารแนบ (`/admin/applicants/{id}`)
- [ ] **2.1 สิทธิ์การเข้าถึง**: บุคคลภายนอกที่ไม่ใช่ Admin ต้องไม่สามารถเข้าหน้านี้ได้ (Redirect ไป `/login`)
- [ ] **2.2 การแสดงผลข้อมูล**: ข้อมูลที่ผู้สมัครกรอกปรากฏครบถ้วนตรงกับแบบฟอร์ม FS-A21-001 (E)
- [ ] **2.3 การเปิดดูไฟล์แบบปลอดภัย (Secure Files)**:
  - คลิกเปิดดูสำเนาบัตรประชาชน และเรซูเม ต้องเปิดดูได้ผ่านสตรีม URL ปลอดภัย
  - ตรวจสอบว่าไฟล์ไม่ได้ถูกเก็บไว้ใน Public URL ที่คนภายนอกเข้าถึงได้ตรงๆ
- [ ] **2.4 บันทึกการตรวจสอบ**:
  - ติ๊กตรวจ Blacklist, คดีอาญา, Social Media และกรอกบันทึก HR Note
- [ ] **2.5 การเปลี่ยนสถานะ**:
  - ทดสอบเลือก **"ผ่านคุณสมบัติ (Qualified)"** -> สถานะเปลี่ยนเป็น `qualified`
  - ทดสอบเลือก **"ไม่ผ่านคุณสมบัติ (Disqualified)"** -> สถานะเปลี่ยนเป็น `disqualified`

---

### TC-03: การออกรหัสสอบและกำหนดวันหมดอายุ (`/admin/applicant-accounts`)
- [ ] **3.1 การเลือกผู้สมัคร**: แสดงเฉพาะผู้สมัครที่ผ่านคุณสมบัติ (Qualified)
- [ ] **3.2 การกำหนด Exam Deadline**: กำหนดวันสุดท้ายที่เข้าสอบได้
- [ ] **3.3 การสร้างรหัสผ่าน**:
  - ระบบ Generate Username และรหัสผ่านสุ่มอัตโนมัติ
  - HR สามารถกดปุ่มดูรหัสผ่าน และมีปุ่มคัดลอก (Copy) เพื่อส่งต่อให้ผู้สมัครได้
  - สถานะผู้สมัครเปลี่ยนเป็น `code_generated`

---

### TC-04: การสร้างและจัดการชุดแบบทดสอบ (`/admin/exams`)
- [ ] **4.1 การตั้งค่าชุดข้อสอบ**:
  - กำหนดชื่อข้อสอบ, คำชี้แจง, เวลาสอบ (เช่น 30 นาที), เกณฑ์คะแนนผ่าน (เช่น 60%)
  - เลือกประเภทเป้าหมาย: ทั้งหมด (All Positions) หรือเฉพาะตำแหน่งที่เลือก
- [ ] **4.2 ข้อสอบปรนัยเลือก 1 ข้อ (Single Choice)**: สร้างโจทย์, ตัวเลือก ก ข ค ง, กำหนดข้อถูก 1 ข้อ
- [ ] **4.3 ข้อสอบปรนัยเลือกหลายข้อ (Multi Choice)**: กำหนดข้อถูกได้มากกว่า 1 ข้อ
- [ ] **4.4 ข้อสอบอัตนัย (Essay)**: สร้างโจทย์คำถามปลายเปิด พร้อมตั้งคะแนนเต็มประจำข้อ
- [ ] **4.5 แนบภาพประกอบโจทย์**: อัปโหลดภาพประกอบข้อคำถามและแสดงผลถูกต้อง

---

### TC-05: การเข้าสอบและระบบตรวจจับการทุจริต (Anti-Cheating Engine)
- [ ] **5.1 การเข้าสู่ระบบสอบ (`/exam/login`)**:
  - กรอก Username และ Password ที่ HR ออกให้
  - ทดสอบล็อกอินด้วยรหัสผิด -> แสดงข้อความแจ้งเตือน
  - ทดสอบล็อกอินด้วยบัญชีที่หมดอายุ (`isExpired`) -> ระบบไม่อนุญาตและปรับสถานะเป็น `failed_test`
- [ ] **5.2 หน้าเตรียมตัวสอบ (`/exam/welcome` & Dashboard)**:
  - แสดงชื่อผู้สอบ, ตำแหน่ง, และชุดข้อสอบที่ต้องทำอย่างถูกต้อง
- [ ] **5.3 เริ่มทำข้อสอบ (`/exam/attempts/{id}/take`)**:
  - เมื่อกดเริ่มทำข้อสอบ ตัวนับเวลาถอยหลัง (Timer) เริ่มทำงานทันที
  - เวลาไม่ถูกรีเซ็ตใหม่เมื่อมีการกด Refresh หน้าจอ
- [ ] **5.4 🛡️ ทดสอบระบบ Anti-Cheating (จุดตรวจสอบสำคัญ)**:
  - **การสลับแท็บ/ย่อหน้าต่าง**: ให้ผู้สอบเปิดแท็บอื่น หรือสลับโปรแกรมไปมา 3 ครั้ง
  - **การออกจากโหมดเต็มหน้าจอ**: ให้ผู้สอบกดยกเลิก Fullscreen
  - **ผลลัพธ์**: ระบบต้องส่ง Request บันทึกไปยัง Database ทันทีโดยที่หน้าจอไม่ค้าง
- [ ] **5.5 การส่งข้อสอบ**:
  - กดส่งข้อสอบสำเร็จ หรือรอให้เวลานับถอยหลังจนหมด ระบบต้องตัดส่งข้อสอบอัตโนมัติ
  - สถานะเปลี่ยนเป็น `awaiting_review`

---

### TC-06: การตรวจให้คะแนนและสรุปผลการสอบ (`/admin/exam-review`)
- [ ] **6.1 คะแนนปรนัยอัตโนมัติ**: ข้อสอบแบบ Single/Multi Choice ได้รับการตรวจและคิดคะแนนทันทีที่ส่ง
- [ ] **6.2 การตรวจข้อเขียนอัตนัย**:
  - HR สามารถอ่านคำตอบ และเปิดดูไฟล์ที่ผู้สอบแนบได้
  - HR กรอกคะแนนที่ให้ (ไม่เกินคะแนนเต็มประจำข้อ) พร้อมบันทึกคำแนะนำได้
- [ ] **6.3 รายงานพฤติกรรมน่าสงสัย (Suspicious Activity Report)**:
  - แสดงตัวเลขจำนวนครั้งที่สลับแท็บ (จากข้อ 5.4 ต้องขึ้นว่าพบ 3+ ครั้ง)
  - มี Log แสดงวันเวลาและเหตุการณ์ (เช่น `visibility_change`, `fullscreen_exit`) อย่างชัดเจน
- [ ] **6.4 การประเมินผลลัพธ์**:
  - หากคะแนนรวมถึงเกณฑ์ % ที่กำหนด -> สถานะเป็น **`passed_test`**
  - หากคะแนนไม่ถึงเกณฑ์ -> สถานะเป็น **`failed_test`**

---

### TC-07: หน้าสรุปผลภาพรวมและรายงาน (`/admin/summary`)
- [ ] **7.1 สรุปสถิติภาพรวม**: ตรวจสอบตัวเลขผู้สมัครทั้งหมด, ผู้ผ่านเกณฑ์, ผู้ตกเกณฑ์
- [ ] **7.2 รายละเอียดผู้สมัครรายบุคคล (`summary/applicants/{id}`)**:
  - แสดงประวัติส่วนตัว, ผลการตรวจของ HR, คะแนนสอบแต่ละชุด และสถานะสรุปสุดท้าย
- [ ] **7.3 การส่งออกข้อมูล / พิมพ์เอกสาร**: ตรวจสอบการจัดหน้าสำหรับสั่งพิมพ์หรือ Export
